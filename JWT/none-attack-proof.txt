Format body:    {"jwt_token":"<token>"}

========================================
WERYFIKACJA POPRAWKI
========================================
Poprawka: w JWT.verify(...) lista algorytmow zmieniona
          z ['none', 'HS256'] na ['HS256'] (app.js, handler /jwt/none).

Po przebudowie obrazu (docker build + docker run) ten sam spreparowany
token zostaje ODRZUCONY:

POST https://127.0.0.1:443/jwt/none   body: {"jwt_token":"<spreparowany token>"}
Odpowiedz serwera:
{"name":"JsonWebTokenError","message":"invalid algorithm"}

Prawidlowy token HS256 nadal przechodzi (zwraca "Congrats!!"),
wiec poprawka nie psuje normalnego logowania.
